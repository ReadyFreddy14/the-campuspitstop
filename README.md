# TheCampusPitStop

A single-page concept and business plan website for a proposed fuel and convenience stop serving University of North Texas students in Denton.

## View locally

Open `index.html` in a browser. The budget and presentation worksheets run in the browser and save entered values on the current device with local storage. No payments or signups are sent to a server.

## Publishing

The files in this repository are static and can be served from the repository root with GitHub Pages. The existing live Site is https://campuspitstop.fasimex104.chatgpt.site/; publishing this repository will create a separate copy, and edits do not synchronize automatically between the two.

## Data and assumptions

Research links appear near relevant claims. The proposed location, competitor pricing scenario, sales volumes, costs, and financial targets are illustrative planning assumptions. The site is not affiliated with or approved by UNT. Local fuel prices change frequently; verify them at the pump.
